# Feedback System

A simple web application that allows users to submit feedback and view submitted feedback.

## Features

- Submit feedback using a form
- Add name, rating, and comments
- View submitted feedback
- Store feedback in MongoDB
- Simple and responsive user interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB

## Installation and Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/sweety275/feedback-system.git
   ```

2. Open the project folder:

   ```bash
   cd feedback-system
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env` file and add your MongoDB connection string and required environment variables.

5. Start the server:

   ```bash
   node server.js
   ```

6. Open `http://localhost:3000` in your browser.

## Project Structure

- `models/` – MongoDB feedback model
- `public/` – HTML, CSS, and JavaScript files
- `server.js` – Express server
- `package.json` – Project dependencies
